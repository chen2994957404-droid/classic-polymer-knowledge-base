\# Classic Polymer Knowledge Base



This repository is a structured workspace for building a classic-and-modern polymer science knowledge base.



\## Project Goal



Convert classic polymer textbook materials into structured, high-quality, Notion-ready learning notes, including:



\- OCR-assisted text extraction

\- Formula correction

\- Conceptual restructuring

\- Tables and diagrams

\- Review questions and answers

\- Modern research extensions

\- Notion-ready exports



\## Workflow



ChatGPT acts as the editor-in-chief and content reviewer.



Codex acts as the engineering assistant for scripts, OCR pipelines, Markdown cleaning, and Notion export tools.



GitHub is used as the version-controlled middle layer.



Notion is used as the final knowledge base interface.



\## Folder Structure



\- `00\_admin/`: project rules and content standards

\- `01\_raw\_local/`: raw textbook PDFs and scanned images, kept local only

\- `02\_ocr\_output/`: OCR outputs and cleaned text drafts

\- `03\_chapter\_notes/`: final chapter notes

\- `04\_figures/`: figures, diagrams, and visual materials

\- `05\_notion\_ready/`: files ready for Notion import

\- `06\_codex\_tasks/`: task prompts for Codex

\- `07\_review\_notes/`: review notes and correction records

\- `scripts/`: scripts written by Codex or manually maintained



\## Copyright Note



Raw textbook PDFs and full OCR text should not be pushed to public repositories. This project is intended for personal academic study and structured knowledge management.
